# Cobalt — décors générés

Décors créés avec imagegen sur autorisation explicite de l’utilisateur, le 17 novembre 2026, à partir de la direction de la planche cobalt. Ils ne documentent pas les lieux du parcours professionnel. Aucun portrait personnel, résultat, interface de projet, logo ou certificat n’a été généré.

Les PNG sont les originaux. Les WebP 800/1600 sont des variantes optimisées (largeur maximale source : 1536 px). Les vraies captures, logos et justificatifs restent séparés et intacts.

## Intentions des prompts de génération

Consigne commune : photographie décorative horizontale 3:2, esthétique Y2K cobalt/cyan, matières réelles et lumière sensible, sans texte, interface, marque ni logo.

- transit : hall ferroviaire vitré à l’heure bleue, vitre mouillée, passants anonymes flous, lumière cyan et bleu pétrole, profondeur photographique.
- rain : gros plan de pluie sur une vitre de train, lumières lointaines diffuses, ambiance intime, silhouettes non identifiables.
- connections : prise RJ45, câbles cyan translucides, verre superposé et matériel informatique crédible, macro photographique.
- journey : passage piéton urbain, passants en mouvement, architecture vitrée cyan, pose longue évoquant le déplacement.
- folio : papier ivoire vierge, pochettes translucides et résine bleue, photographie de matières, sans texte ni sceau.
- sky : nuages lumineux dans un ciel cobalt, reflets sur une eau calme, lumière naturelle expressive.

La planche de référence n’est pas publiée comme image du site.
