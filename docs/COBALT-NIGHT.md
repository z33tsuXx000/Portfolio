# Déclinaison nocturne cobalt

Palette appliquée aux surfaces et aux textes, sans filtre sur les photographies. Les logos disposent des adaptations sombres déjà fournies ; les originaux restent dans le dépôt.

Correction Projets : la séquence SOC était auto-placée dans une colonne de la grille avec une marge gauche de 36 %. Elle occupe désormais une seconde rangée complète. Sur desktop, capture et texte se partagent cette largeur ; sur mobile ils se succèdent.

Vérifications : FR/EN, desktop 1440 px, mobile 390/360 px, six rubriques, domaines, étapes, certifications, projets et retour du focus. Test spécifique de transitions interrompues : aucune couche sortante restante ni transformation persistante. Liens directs, historique, réduction des animations et contenu sans JavaScript vérifiés.

Contrastes calculés sur ardoise #1B2C48 : texte 11,86:1 ; secondaire 7,81:1 ; lien pervenche 6,12:1. Blanc sur sélection cobalt : 6,62:1. Ces mesures concernent les aplats, pas chaque pixel photographique.
