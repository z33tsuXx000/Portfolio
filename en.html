Project Overview

Design and deployment of a virtualized SOC homelab built to reproduce the core functions of a Blue Team environment. The lab centralizes security events from multiple systems to enable monitoring, detection and analysis through a SIEM/XDR platform.

The project also includes controlled security scenarios designed to generate realistic alerts and reproduce the first stages of a SOC analyst workflow: telemetry collection, event triage, analysis, contextualization and investigation.

SOC Architecture

The environment is built around several virtual machines, including Windows and Linux endpoints monitored by Wazuh agents. Events are centralized on the Wazuh server, where they are analyzed, correlated and displayed through the SOC dashboard.

Detection & Investigation

Multiple scenarios are executed within the lab to generate security events that can be observed through Wazuh. The goal is to reproduce a SOC triage workflow by identifying the source of each event, its context and severity, as well as relevant information for further investigation.

AI-Assisted Triage

An AI layer is integrated into the workflow to assist with the analysis of security alerts generated by the SOC. Events can be sent to a local language model through an automated pipeline to produce a concise and actionable summary for the analyst.

The model can help identify relevant information within an alert, summarize the observed behavior, provide additional context and suggest possible next steps for further investigation.

Key Implementations

  • Deployment and configuration of a Wazuh SIEM/XDR platform
  • Monitoring of Windows and Linux endpoints
  • Centralization and analysis of system and security events
  • Creation of security scenarios to generate detection alerts
  • Alert analysis and triage through the Wazuh dashboard
  • Use of the MITRE ATT&CK framework to contextualize detections
  • Integration of a local LLM into the analysis workflow
  • Automated alert enrichment using Python and APIs

Technologies: Wazuh, Windows, Linux, Sysmon, MITRE ATT&CK, Python, PowerShell, REST API, Local LLM, Virtualization
