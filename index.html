SOC / 01

Vue d’ensemble

Conception et déploiement d'un homelab SOC virtualisé visant à reproduire les principales fonctions d'un environnement Blue Team. Le laboratoire centralise les événements de sécurité provenant de différents systèmes afin de permettre leur supervision, leur détection et leur analyse depuis une plateforme SIEM/XDR.

Le projet permet également de générer différents scénarios de sécurité contrôlés afin d'obtenir des alertes réalistes et de reproduire les premières étapes du travail d'un analyste SOC : collecte de télémétrie, qualification d'événements, analyse, contextualisation et investigation.

SOC / 02

Architecture du SOC

L'environnement repose sur plusieurs machines virtuelles, comprenant notamment des endpoints Windows et Linux supervisés par des agents Wazuh. Les événements sont centralisés sur le serveur Wazuh afin d'être analysés, corrélés et présentés depuis le dashboard SOC.

SOC / 03

Détection & investigation

Plusieurs scénarios sont exécutés dans le laboratoire afin de générer des événements de sécurité observables depuis Wazuh. L'objectif est de reproduire un workflow de triage SOC en identifiant la source de l'événement, son contexte, sa sévérité ainsi que les éléments utiles à une investigation plus approfondie.

SOC / 04

Triage assisté par IA

Une couche d'intelligence artificielle est intégrée au workflow afin d'assister l'analyse des alertes remontées par le SOC. Les événements peuvent être transmis à un modèle de langage local via un pipeline automatisé afin de produire une synthèse exploitable par l'analyste.

Le modèle peut notamment aider à identifier les informations importantes d'une alerte, résumer le comportement observé, contextualiser l'événement et proposer des pistes d'investigation complémentaires.

SOC / 05

Mise en œuvre

  • Déploiement et configuration d'une plateforme Wazuh SIEM/XDR
  • Supervision d'endpoints Windows et Linux
  • Centralisation et analyse des événements système et sécurité
  • Création de scénarios permettant de générer des alertes de sécurité
  • Analyse et triage d'alertes depuis le dashboard Wazuh
  • Utilisation du framework MITRE ATT&CK pour contextualiser les détections
  • Intégration d'un LLM local dans le workflow d'analyse
  • Automatisation de l'enrichissement des alertes via Python et API

Technologies : Wazuh, Windows, Linux, Sysmon, MITRE ATT&CK, Python, PowerShell, REST API, Local LLM, Virtualisation

Vue d’ensemble

Conception et déploiement d'un homelab SOC virtualisé visant à reproduire les principales fonctions d'un environnement Blue Team. Le laboratoire centralise les événements de sécurité provenant de différents systèmes afin de permettre leur supervision, leur détection et leur analyse depuis une plateforme SIEM/XDR.

Le projet permet également de générer différents scénarios de sécurité contrôlés afin d'obtenir des alertes réalistes et de reproduire les premières étapes du travail d'un analyste SOC : collecte de télémétrie, qualification d'événements, analyse, contextualisation et investigation.

Architecture du SOC

L'environnement repose sur plusieurs machines virtuelles, comprenant notamment des endpoints Windows et Linux supervisés par des agents Wazuh. Les événements sont centralisés sur le serveur Wazuh afin d'être analysés, corrélés et présentés depuis le dashboard SOC.

Détection & investigation

Plusieurs scénarios sont exécutés dans le laboratoire afin de générer des événements de sécurité observables depuis Wazuh. L'objectif est de reproduire un workflow de triage SOC en identifiant la source de l'événement, son contexte, sa sévérité ainsi que les éléments utiles à une investigation plus approfondie.

Triage assisté par IA

Une couche d'intelligence artificielle est intégrée au workflow afin d'assister l'analyse des alertes remontées par le SOC. Les événements peuvent être transmis à un modèle de langage local via un pipeline automatisé afin de produire une synthèse exploitable par l'analyste.

Le modèle peut notamment aider à identifier les informations importantes d'une alerte, résumer le comportement observé, contextualiser l'événement et proposer des pistes d'investigation complémentaires.

Mise en œuvre

  • Déploiement et configuration d'une plateforme Wazuh SIEM/XDR
  • Supervision d'endpoints Windows et Linux
  • Centralisation et analyse des événements système et sécurité
  • Création de scénarios permettant de générer des alertes de sécurité
  • Analyse et triage d'alertes depuis le dashboard Wazuh
  • Utilisation du framework MITRE ATT&CK pour contextualiser les détections
  • Intégration d'un LLM local dans le workflow d'analyse
  • Automatisation de l'enrichissement des alertes via Python et API

Technologies : Wazuh, Windows, Linux, Sysmon, MITRE ATT&CK, Python, PowerShell, REST API, Local LLM, Virtualisation
